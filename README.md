# Diba CRM — Contacts UI

نسخه‌ی اولیه‌ی رابط کاربری پنل مدیریت مخاطبین دیبا بانک، با همان امکانات نسخه‌ی قبلی و با اضافه شدن Responsive UI و ساختار دو سایدبار مطابق طرح مرجع.

## Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- lucide-react

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## Build

```bash
npm run build
npm run preview
```

## امکانات فعلی

- RTL کامل و فارسی
- Header
- سایدبار اصلی سمت راست با آیتم‌های همه مخاطبین، تنظیمات نام کاربری و رمز ورود، نحوه آشنایی، افزودن نقش و افزودن دسته
- سایدبار پیمانکاران در سمت چپ در نمایش دسکتاپ
- منوی موبایل برای دسترسی به هر دو سایدبار در نمایشگرهای کوچک
- جدول مخاطبین
- جستجو، فیلتر، مرتب‌سازی و Pagination
- انتخاب تعداد آیتم‌های قابل نمایش در هر صفحه: ۸، ۱۶، ۲۴ و ۳۲
- افزودن، ویرایش و حذف مخاطب
- فرم چندشماره‌ای با نوع تلفن ثابت / موبایل
- Mock Data
- لایه‌ی Service جدا از UI برای اتصال آسان‌تر به API واقعی

## ساختار

- `src/features/contacts` — ماژول مدیریت مخاطبین
- `src/services/contacts.service.js` — لایه‌ی دیتا؛ فعلاً Mock
- `src/data/contacts.js` — داده‌های Mock
- `src/components` — کامپوننت‌های عمومی UI و Layout

وقتی API واقعی آماده شد، هدف این است که منطق ارتباط با Backend در `contacts.service.js` جایگزین شود و UI کمترین تغییر را داشته باشد.
